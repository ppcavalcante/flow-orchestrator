# Receipt B1 — E-read: authoritative submission inspection & recovery discovery

**Re:** `openai-workflow/docs/plans/security-workflow-architecture/engine-input-aware-factory-handoff.md` §14.B1
**Status: DELIVERED (rev 2, after §15 R3).** A new read-only public surface — **separate from E-01** — for by-ID
submission inspection and bounded, resumable discovery over the durable work queue. Additive; no persisted-format
change; no existing behavior changed. Same-model self-review, not independent certification.

> **Rev 2 — §15 R3 corrections.** (1) The discovery contract is restated as a **finite per-page sweep, not a
> lossless change feed** — a filter-membership change *behind* the cursor is not caught by continuing that sweep
> (witness `TestERead_ListSubmissions_FilterMembershipChangeBehindCursor`); use a fresh sweep or tracked-ID
> rechecks for concurrent completeness. (2) The example no longer logs raw `Input` (it is opaque caller payload).
> (3) The `WorkflowStatus` comparison is corrected — its gap was **missing original type/input**, not a lack of
> queue lifecycle authority. (4) `QueuedSubmission` now carries `OwnerHost` (the §14.B2 binding), so a caller can
> fail closed on a run's host identity.

## 2. Public API

```go
// Authoritative durable record of one submission, read straight from the work_queue row (journal-independent).
type QueuedSubmission struct {
    WorkflowID      string
    Type            string
    Input           []byte // EXACT original queued bytes (defensive copy)
    State           string // pending | claimed | done | failed | cancelled
    Attempts        int
    EnqueuedAt      int64  // unix-nanos (the FIFO ordering key)
    UpdatedAt       int64  // unix-nanos of the last lifecycle transition
    ParentID        string // "" when not a sub-workflow child (engine-set control column)
    ParentSignal    string // "" when not a sub-workflow child (engine-set control column)
    Depth           int    // sub-workflow nesting depth (0 for a plain dispatch)
    CancelRequested bool   // the durable operator-cancel intent flag is set
    OwnerHost       string // §14.B2 host binding ("" = generic); validate before a host-local drive
}

// By-ID inspection. ErrNotFound when there is no row (distinct from a storage failure).
func (s *SQLiteStore) InspectSubmission(workflowID string) (*QueuedSubmission, error)

// Bounded, resumable discovery. states=nil ⇒ all states (incl. terminal). limit clamped to [1,1000].
type SubmissionCursor struct { EnqueuedAt int64; WorkflowID string }
type SubmissionPage   struct { Items []QueuedSubmission; Next *SubmissionCursor }
const (
    DefaultSubmissionPageLimit = 100
    MaxSubmissionPageLimit     = 1000
)
func (s *SQLiteStore) ListSubmissions(states []string, limit int, after *SubmissionCursor) (SubmissionPage, error)
```

Both require an mp store (the `work_queue` table only exists there). No private SQL is exposed; the application
does not copy dispatch.

## 3. Contract satisfied (per §14.B1)

- **By-ID original type + exact input + authoritative lifecycle** — `InspectSubmission` reads them from the
  durable queue row, so they are **independent of any mutable journal value** (witness:
  `TestERead_InspectSubmission_IndependentOfJournal` — a journal with a different value under the same id does
  not change the recovered input).
- **Works for records that never obtained a journal** — pending, claimed, and terminal **failed/cancelled**
  rows with no journal are all recoverable (witness: `TestERead_InspectSubmission_ByIDAllStatesIncludingNoJournal`,
  which asserts `Load(id) == ErrNotFound` for the failed row yet `InspectSubmission` still returns its type/input).
- **Distinguishable not-found vs storage failure** — missing id → `ErrNotFound`; a storage fault →
  `ErrBusy`/`ErrIO`/`ErrCorruptData`, never `ErrNotFound` (witness:
  `TestERead_InspectSubmission_NotFoundVsStorageFailure`, which drops the table and asserts
  `NotErrorIs(err, ErrNotFound)`).
- **Bounded, resumable discovery including terminal queue-only submissions** — `ListSubmissions` orders by the
  immutable keyset `(enqueued_at, workflow_id)`, pages by cursor, clamps `limit` so a call is never an unbounded
  dump, and includes terminal rows (witnesses: `..._PaginationResumeNoOmissions` paginates 25 rows across
  pending+terminal at bound 10 and proves each id discovered exactly once; `..._StateFilterAndOrdering` proves
  terminal `failed` rows are discoverable and FIFO-ordered; `..._LimitBounds` proves `limit<=0` clamps to the
  default page bound with a continuation cursor rather than dumping the table).
- **Ordering / cursor / concurrent-change semantics documented — a finite per-page sweep, NOT a lossless change
  feed** (§15 R3): keyset over immutable columns ⇒ within one forward sweep no row that stays in the filter is
  skipped or duplicated, and a row appended after the cursor is observed on continuation. But each page is
  point-in-time (not a cross-page snapshot), and a row whose **filter membership changes behind the cursor** is
  **not** caught by continuing that sweep — use a **fresh sweep** or track ids and re-`InspectSubmission` them for
  concurrent completeness (witnesses: `..._ConcurrentChangeSemantics`, `..._FilterMembershipChangeBehindCursor`).
- **Not a silent substitute** — this does **not** reuse `ListPending` (pending-only, unbounded, no cursor) or
  journal-only enumeration. `WorkflowStatus` reports queue lifecycle + a journal-derived node tally but is
  **missing the original queued type/input** — that gap (not any lack of lifecycle authority) is what E-read
  fills; `WorkflowStatus` remains as-is.

## 4. Application-usable example

```go
// Inspect one submission by id.
sub, err := store.InspectSubmission(id)
switch {
case errors.Is(err, workflow.ErrNotFound):
    // no such submission (distinct from a read failure)
case err != nil:
    // storage/corruption failure — retry or alert
default:
    // Do NOT log raw sub.Input — it is opaque caller payload (may carry sensitive data). Log metadata only.
    log.Printf("type=%s state=%s host=%s attempts=%d inputLen=%d",
        sub.Type, sub.State, sub.OwnerHost, sub.Attempts, len(sub.Input))
}

// Discover every terminal submission, resumably, in bounded pages.
var cursor *workflow.SubmissionCursor
for {
    page, err := store.ListSubmissions(
        []string{"done", "failed", "cancelled"}, 200, cursor)
    if err != nil { return err }
    for _, s := range page.Items {
        // recover s.Type / s.Input for a record that may have no journal
    }
    if page.Next == nil { break }
    cursor = page.Next
}
```

## 5. Compatibility

- **Additive only.** Two new methods + three new exported types + two new constants on `*SQLiteStore`. No change
  to any existing signature, the `Observability` interface, the schema, the journal, or dispatch behavior. No
  persisted-format migration.
- Not added to the `Observability` interface deliberately — adding a method to an exported interface would break
  any external implementer; these are standalone `*SQLiteStore` methods.

## 6. Unresolved / out of scope

- Read-only by design: no lifecycle mutation, no admission — that is B2's contract, delivered separately.
- Point-in-time-per-page (not repeatable-read across pages) is the documented trade for O(1) memory and
  unbounded-dataset resumability; a caller needing a fully consistent multi-page view must quiesce writes or
  snapshot externally.
